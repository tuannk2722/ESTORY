# P3-01 — Contract Freeze & Compatibility Bridge

Ngày xác minh: **2026-09-05**. Baseline: `b3872b7`; user đã xác nhận CI và Vercel của P3-00 pass trước khi bắt đầu stage này.

## Phạm vi

Stage này chốt contract kỹ thuật Effect và Scene snapshot v1, thêm bridge đọc JSON legacy, và giữ nguyên JSON làm nguồn persistence production. Không thêm Prisma, migration, auth, storage hoặc cutover Reader sang database.

## Kết quả

- Technical Effect manifest là nguồn duy nhất cho 25 EffectType: ID, category, icon key, defaults, allowed scopes và constraints. Icon React nằm ở module client riêng; `EFFECT_METADATA` vẫn là compatibility projection cho consumer cũ.
- Projector tạo DTO serializable từ technical manifest + metadata overlay. Overlay không thể sửa category, defaults, scopes, constraints hoặc icon key; trạng thái inactive không làm mất renderer của nội dung đã lưu.
- `SceneRenderConfig.schema_version = 1` có Zod parser strict cho image, video, linear gradient, radial gradient, particle composition, palette và ambient effects.
- Theo quyết định được user duyệt ngày 2026-09-05, schema v1 có thêm `radial_gradient` với shape `circle|ellipse`, tâm chuẩn hóa 0..1, ordered stops và extent cố định `farthest-corner`. Bốn nền radial legacy được giữ nguyên bằng typed snapshot, không dùng raw CSS trong target contract.
- Mapper legacy xử lý image/video/gradient/radial/particle; `background_tint` legacy được tách thành màu opaque và opacity `0.35`. Preset và custom draft đều tạo deep copy; snapshot không giữ tham chiếu mutable về catalog.
- `SceneLayer` chỉ nhận `SceneRenderConfig`. Reader và Scene Preview hiện tại vẫn dùng JSON legacy nhưng resolve snapshot trước renderer.
- Target repository nhận đủ `storyId + chapterId`; public chapter aggregate trả Scene snapshot và kiểm tra public Story/Chapter trước khi đọc Scene. JSON adapter fail khi chapter ID legacy mơ hồ, range sai/chồng lấn hoặc snapshot sai schema.
- Catalog target chỉ trả record active phù hợp. Scene snapshot đã lưu tiếp tục đọc được khi ingredient catalog bị archive/xóa vì target read không resolve catalog ID.
- Đã thêm `ApiSuccess`/`ApiFailure` và command interfaces cho Story, Chapter, Scene; implementation transaction/authorization được để đúng stage P3-06.

## Tương thích và giới hạn đã biết

- Production routes và editor vẫn đọc/ghi JSON shape legacy qua interface compatibility có ràng buộc story/chapter. Chưa đổi production persistence source.
- Seed đang tham chiếu `/scene-backgrounds/rain-loop.mp4` chưa tồn tại. Parser vẫn cho legacy hoạt động vì snapshot hợp lệ; `assertLocalSceneMedia` sẽ làm migration dry-run P3-04 fail rõ ràng cho tới khi asset được bổ sung hoặc mapping được sửa.
