# P3-06 — DAL, authorization & Story/Chapter/Scene commands

Ngày kiểm tra: 2026-09-08. Starting HEAD: `9ad3bc9` (P3-05).
Implementation và các gate local/Neon dev bên dưới đã pass. Chưa push/deploy changeset;
GitHub Actions và Vercel vẫn cần kết quả của môi trường tương ứng.

## Phạm vi đã triển khai

- Dùng session/role P3-03; bổ sung Story owner/admin, Chapter membership và mutable-state
  guards tại DAL và transaction. Guest `401`, thiếu role `403`, khác owner/membership
  và missing resource cùng `404`, không trả thông tin resource không được phép.
- Commands tạo/cập nhật/gửi duyệt/rút gửi/gỡ/khôi phục Story; tạo/đổi tên/reorder/xóa/
  publish Chapter; replace blocks, Scene snapshots và editor aggregate. Byline và
  reader→author được xử lý trong transaction tạo truyện theo quyết định đã ghi ở
  [12 §12.5](../12-auth-and-author-management.md#125-luồng-tạo-truyện-mới--authorstoriesnew-wizard-2-bước).
- Transaction-scoped `PrismaStoryCommandRepository` mở rộng StoryRepository hiện có;
  `StoryCommandTransactions` dùng Serializable và conditional update `Story.updatedAt`.
  Mọi mutation nhận revision và tăng revision aggregate; stale/concurrent update `409`.
  Snapshot của một command và revision trả về thuộc cùng transaction.
- Pending review khóa mutation của author; admin override ownership/pending lock,
  vẫn tuân thủ state machine, revision và rule chương cuối. Archive phải restore
  trước khi sửa. Submit kiểm metadata/byline và ít nhất một chương có blocks.
- Editor aggregate thay Chapter blocks + Scenes nguyên tử, lỗi rollback toàn bộ.
  Thay text không resolve lại catalog hoặc thay snapshot; Scene range sai/overlap,
  ID khác chapter, malformed snapshot và provenance mới không hợp lệ bị từ chối.
- Routes P3-06 dùng strict Zod DTO/output, envelope thống nhất, origin check,
  byte-limit 4,000,000 cho JSON body; chặn cả body vượt limit không có/khai sai
  Content-Length. Errors không serialize ORM causes/query/content vào response/log.
- Runtime generic Story save và legacy Scene save bị chặn. Write flag mặc định vẫn
  `json`, nay có nghĩa là tắt runtime content writes; không ghi fallback về JSON.
  Write opt-in yêu cầu cả hai read sources là Prisma. Không đổi file env đang dùng.
- Page editor thêm ownership/membership guard; client snapshot/envelope conversion
  vẫn thuộc P3-07. Payload legacy không được lách qua route để ghi JSON/DB.
- CI bổ sung `test:commands:db` và `test:commands:http`. Không thêm dependency,
  không thay schema/migration/lockfile/content seed.

Contract, route inventory và vận hành nằm tại [README](../../README.md#dal--content-commands-p3-06)
và [11 §9.5](../11-phase3-technical-roadmap.md#95-auth-settings-sync-phân-quyền).

## Ranh giới và gate bên ngoài

- Chưa xác nhận GitHub Actions/Vercel cho changeset này; không coi local build là
  deploy verification. Không commit/push hoặc deploy trong task.
- Production writes chưa bật. UI editor cũ chưa gửi canonical snapshot/expectedUpdatedAt;
  write hợp lệ bị `503` khi flag tắt, DTO legacy sai contract bị `400`. P3-07 phải nối
  client, kiểm round-trip trên preview và hoàn tất backup/PITR trước production write.
- P3-10 sở hữu form/dashboard; P3-11 sở hữu approve/reject; P3-12–16 sở hữu các
  catalog/media integrations. Không thêm Story hard-delete hoặc Admin mutations ở gate này.
- Error mapper đã hỗ trợ `429`; không tuyên bố có distributed rate limiter cho
  content commands. Quota/upstream rate limiting vẫn thuộc các integration stage.

## Rollback

Không có schema migration mới. Giữ content write tắt; không mở lại đường ghi JSON để
lách guards. Nếu đã bật command write trên dev/preview, dùng DB restore/PITR hoặc
forward fix cho dữ liệu đó, không lấy JSON làm nguồn rollback. Production cutover và
restore drill thực hiện ở P3-07 theo [roadmap](../11-phase3-technical-roadmap.md#93-dbauthmigrationcutover--thứ-tự-an-toàn).
