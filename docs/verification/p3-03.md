# P3-03 — Auth.js & bootstrap admin

Ngày kiểm tra: 2026-09-07. Starting HEAD: `3065d8f` (P3-02); user xác nhận baseline xanh.

## Phạm vi triển khai

- Auth.js `5.0.0-beta.32`, Prisma adapter `2.11.3` pin exact; không thay Prisma schema/migration.
- Google/GitHub OAuth, database session, user ID ổn định, role từ DB và session projection allowlist.
- Provider email verification; không tự liên kết account theo email; redirect giới hạn AUTH_URL.
- `requireSession`/`requireRole`, rank reader < author < admin; proxy chỉ redirect sớm.
- Page và API editor legacy tạm admin-only do JSON chưa có owner đáng tin cậy;
  P3-06 hoàn thiện owner/membership. Public reads giữ nguyên. PUT thêm Origin check.
- Bootstrap CLI promote-only qua email/ID allowlist, một transaction, mọi selector phải
  khớp đúng một OAuth user, không tạo user/hạ admin/endpoint public; log chỉ counts.
- Startup fail-fast cấu hình Auth; build không cần credential. Browser bundle scan bổ sung auth markers.
- Hướng dẫn vận hành ở README; CI thêm Auth DB/HTTP integration trên PostgreSQL tạm.

Nguồn yêu cầu: `02` §2.5; `07` US-3.3/3.5; `11` §9.5; `12` §12.1–12.3;

DB/HTTP automated tests dùng fixture và đã cleanup. Gate admin vận hành được xác minh
riêng sau khi user đăng nhập GitHub thực. User tự điền Auth/allowlist vào `.env.local`;
agent không sửa file hay in credentials.

Allowlist cấu hình có 2 email, mới 1 email có OAuth user. Lệnh ban đầu với toàn bộ
allowlist thất bại trước khi đổi role (0 admin). Sau khi đối chiếu đúng tài khoản
GitHub có session hoạt động và thuộc allowlist, chạy cùng CLI hai lần với env chỉ có
hiệu lực trong process: `BOOTSTRAP_ADMIN_EMAILS` rỗng, `BOOTSTRAP_ADMIN_USER_IDS` là
exact ID của tài khoản đã đối chiếu. Không ghi ID/email/token vào hồ sơ hoặc log.
`.env.local` giữ nguyên; email thứ hai chưa được bootstrap. Chạy CLI với toàn bộ
allowlist vẫn yêu cầu tài khoản thứ hai đã đăng nhập hoặc chọn phạm vi phù hợp.

## Rollback

Không có schema migration mới. Giữ JSON content flags như P3-02. Nếu cần vô hiệu hóa
Auth, dừng deployment bị lỗi hoặc forward fix; không mở lại editor API không có guards.
User/Account/Session nằm trong các bảng đã tạo P3-02; không xóa dữ liệu Auth để rollback
code. Thu hồi một admin là thao tác vận hành riêng với exact user ID, luôn giữ một admin
khác; bootstrap không thực hiện demotion.
