## Trạng thái exit gate

Implementation và verification local đã hoàn tất. Chưa đánh dấu exit gate
toàn bộ 100% vì các bước trên môi trường thật chưa chạy trong task này:

- Commit/push workflow, quan sát job `Node 24 validation` pass trên GitHub;
  đặt làm required status check nếu branch protection chưa bật.
- Xác nhận Vercel dùng Node 24 và pnpm 10.33.0 trong build log, bật Corepack
  theo README trước khi deploy.

Giữ phần xóa npm lockfile thành commit riêng khi commit changeset này.
Sau khi có bằng chứng CI/deployment runtime, bước tiếp theo là contract và
compatibility bridge theo roadmap mục 9.7. Chưa triển khai bước đó trong task này.
