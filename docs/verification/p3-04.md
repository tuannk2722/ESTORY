# P3-04 — Migration dry-run → apply → verify

Ngày kiểm tra: 2026-09-07. Starting HEAD: `173d594` (P3-03); user xác nhận baseline
P3-03 xanh. P3-04 đã hoàn tất trên Neon dev theo đúng chuỗi dry-run → apply lần 1 →
apply lần 2 → verify.

## Phạm vi đã triển khai

- CLI `pnpm migrate:phase3 -- --mode=dry-run|apply|verify`, bắt buộc đúng một mode và
  `LEGACY_OWNER_USER_ID` khớp user đã tồn tại.
- Parser nguồn fail-closed cho Story/Chapter/Block/Effect, Scene và ba catalog JSON;
  kiểm tra ID/order/membership/range/overlap rồi dùng mapper P3-01 tạo snapshot v1.
- Media audit root-relative theo existence, byte count và SHA-256. HTTPS source chưa có
  trong fixtures và bị chặn nếu không thể checksum trong môi trường chạy migration.
- Transactional upsert giữ stable legacy ID/Story slug, public status, block order/text,
  effect config, Scene provenance/snapshot và không xóa row ngoài seed.
- Effect manifest sync tạo overlay thiếu, giữ overlay đã tồn tại, fail nếu DB có technical
  ID lạ. Dictionary dùng NFKC + lowercase `vi-VN` + trim/collapse whitespace, weight
  `round(baseConfidence * 100)`, key/duplicate resolution deterministic.
- Curated preset giữ stable ID, `sourceVersion = 1`, checksum source và snapshot; lần sync
  sau chỉ cập nhật source fields, không ghi đè metadata/lifecycle do Admin sở hữu.
- Verify đối chiếu expected IDs/counts, owner, slug, status, order/text/effect config,
  catalog/Scene JSON codecs, preset checksum, 25 manifest/overlay IDs, keyword rows và
  global/personal background isolation. Runtime vẫn đọc/ghi JSON.
