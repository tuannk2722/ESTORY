# P3-14 — Scene Authoring v2, Auto Treatment & Legacy Catalog Retirement

Baseline xác minh: **2026-09-19** trên Windows, Node 24, Neon development, production build
cục bộ, Edge headless và bucket R2/custom domain thật. Implementation và các kiểm tra code/runtime
trực tiếp đã hoàn tất. Stage P3-14 chưa đạt toàn bộ gate: strict P3-04 seed parity đang fail vì dữ
liệu runtime ghi riêng bên dưới; GitHub Actions và Vercel Preview chưa chạy vì changeset chưa được
push/deploy.

## Kết quả triển khai

- `SceneRenderConfig` là strict discriminated union v1/v2. Parser v1 giữ các CSS color legacy;
  v2 chỉ serialize lowercase `#rrggbb`, nhận treatment `auto|original` và để renderer clamp aura.
- Scene mới dùng Background-first và chỉ có `Tự động` mặc định hoặc `Giữ màu gốc`. Click lại
  `Nền hiện tại`, mở/đóng editor, sửa text/effect hoặc save thụ động không convert Scene v1.
  Thay Background/treatment rõ ràng mới tạo snapshot v2 và bỏ provenance preset cũ.
- Auto derivation chạy trong Author client từ image, video poster hoặc typed gradient. Pipeline
  quantize/score deterministic lưu resolved accent/aura + version; media không có hue, particle
  hiện chưa có source hint, timeout/decode/CORS lỗi đều fallback Original và không chặn Save.
- Reader chỉ dùng snapshot. V2 không có full-screen color wash; Auto có aura nhẹ, Original không
  color-grade, cả hai dùng neutral readability scrim. Body, heading, Drop Cap và nhãn nhỏ giữ màu chữ AA;
  accent dùng cho viền/ánh sáng trang trí. Treatment key gồm toàn bộ resolved aura để crossfade.
- Background search dùng AND-token substring bỏ dấu/case trên một document gồm ID, label và toàn
  bộ mood tags. Reader không request catalog hoặc import derivation pipeline.
- Palette/Preset bị ẩn khỏi Admin/Author flow mới. Palette GET compatibility là read-only và mọi
  capability đều false; create/update/transition/delete trả `410` ở HTTP lẫn service. API không
  cho tạo Scene v1, gắn provenance mới, xóa provenance thụ động hoặc downgrade v2 → v1.
  Tables, rows, parser v1, snapshot và provenance cũ vẫn được giữ tới P3-17.
- Live catalog interface chỉ expose active global Background. Palette/Preset compatibility reads
  và bridge JSON cũ được tách thành interface/export riêng, tránh quay lại aggregate authoring.
- Admin Scene Catalog còn Background-only; drawer giữ focus ổn định qua re-render, focus error
  summary đúng, upload hiện media đang dùng và menu đóng bằng outside click/Escape.

## Gate P3-04 seed parity chưa đạt

`pnpm migrate:phase3 -- --mode=verify` chạy read-only, hoàn tất counts/hash/media rồi trả exit 1
vì đúng hai khác biệt giữa seed JSON và dữ liệu runtime trên Neon dev:

- Chapter `ck-ch2`: DB đang là `DRAFT`, seed là `PUBLISHED`.
- Background `bg-leviathan-surge`: một gradient stop trong DB là `#c5c372`, seed là `#0f172a`.

Không có mismatch Palette, ScenePreset, Scene compatibility hoặc media. Không chạy
`migrate:phase3 -- --mode=apply`, vì apply sẽ ghi đè thay đổi Author/Admin thật. Nếu dự án vẫn yêu
cầu strict seed parity sau khi đã bật runtime writes, cần quyết định riêng: khôi phục hai row về seed,
hoặc đổi gate P3-04 thành báo cáo/classification drift cho mutable content. P3-14 không tự chọn một
trong hai hướng đó.

## Follow-up Reader visual policy (2026-09-20)

- Renderer v2 giữ neutral scrim nhưng mở rộng ra viewport và fade ở hai gutter ngoài `max-w-2xl`, bỏ mép dọc của khung `max-w-4xl`. Vùng chữ vẫn nhận ít nhất opacity `0.58` theo phép đo contrast hiện có.
- Accent v2 dùng token `--scene-*` riêng. Chữ heading, Drop Cap và nhãn nhỏ giữ `#F8FAFC`; accent nằm ở viền/ánh sáng trang trí. Nút điều hướng chương tiếp tục dùng token theme của ứng dụng. Renderer v1 và snapshot Palette cũ giữ nguyên đường render.
- Scene Picker Preview dùng `settings.font_size` giống `ReaderPane`; canvas chữ truyện vẫn Cinematic Dark trong cả ba app theme.
- Admin Background Preview bỏ Palette mặc định P3-13 và dùng `SceneLayer` v2 `original` trong khung 16:9; neutral scrim phủ trọn khung nhỏ để không xuất hiện dải sáng hẹp ở mép. Thumbnail giữ Background tĩnh chưa phủ màu. Preview Palette compatibility chỉ dùng Palette được truyền tường minh. Edge fixture với Background gradient sáng ở 375/768/1280 px không tràn khung và có ảnh QA local trong `../.tools/p3-07-browser/artifacts/catalog-preview-original-*.png`.
- `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm build` đều pass. Fixture cô lập render `SceneLayer` + `StoryBlock` + `ChapterNav` với CSS production trên Edge headless ở 375/768/1440 px và Light/Sepia/Dark: mask hiện diện, chữ sáng, không tràn ngang, màu nút theo app theme. Đây là kiểm tra renderer/CSS, chưa thay thế smoke end-to-end của Scene đã lưu trên Reader công khai.

## Rollback

- Không rewrite/xóa Scene v1, `ColorPalette`, `ScenePreset` hoặc provenance legacy.
- Scene v2 là self-contained snapshot. Rollback chỉ dùng code vẫn đọc được v2 hoặc forward fix.
- Không quay runtime write về JSON và không sửa/xóa migration P3-04. Palette/Preset compatibility
  chỉ được drop bằng forward migration sau reference audit P3-17.
